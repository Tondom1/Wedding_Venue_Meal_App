One-time upgrade needed

This version of the app needs to add a few things to your saved meals database (for example, moving each meal's ingredients into the new ingredients table). Your meals will not be changed or deleted, and a backup copy is made automatically first.

  1. Go to the terminal running the app and press Ctrl + C to stop it.
  2. Run: 
    .\.venv\Scripts\python -m flask --app app migrate
  3. Start the app again: 
    .\.venv\Scripts\python -m flask --app app run
